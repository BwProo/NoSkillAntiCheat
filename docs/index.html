NoSkillAntiCheat ist ein kostenloses, leichtes Anticheat für Minecraft-Server. Es simuliert jede Bewegung, prüft Kampfverhalten, erkennt Cheat-Clients wie Meteor und lernt mit einer lokalen KI dazu – ohne Cloud, ohne Abo.

Was drin steckt

Aufgebaut auf der bewährten Bewegungs-Simulation von GrimAC, erweitert um Kampf-Heuristiken, Client-Erkennung, Plugin-Schutz und eine KI-Pipeline.

🧭

Bewegungs-Simulation

Jede Bewegung wird 1:1 nachgerechnet. Flight, Speed, NoFall, Phase, Step und Timer fallen auf – mit Ping-Ausgleich und Setbacks.

⚔️

Kampf-Checks

KillAura, AimAssist, TriggerBot, AutoClicker, Reach, Hitboxes, CrystalAura und AnchorAura.

🛰️

Meteor-Erkennung

Erkennt Meteor beim Beitritt über die Schild-Übersetzungs-Probe, auch wenn der Client seinen Namen versteckt.

🧠

Lokale KI

Sitzungen aufnehmen, Modell auf dem eigenen PC trainieren, im Plugin bewerten. Kostenlos und ohne Cloud.

🙈

Plugin-Schutz

Blockt /pl, /plugins, /version, /help und versteckt Plugins aus der Tab-Vervollständigung. Server-Typ wird als „vanilla“ angezeigt.

⛏️

Anti-Xray

Schaltet den eingebauten Anti-Xray von Paper, Purpur und Folia auf Wunsch automatisch ein.

🪶

Lightweight

Checks laufen auf dem Netty-Thread, nichts blockiert Main- oder Region-Threads. Folia wird voll unterstützt.

💬

Klare Alarme

Kompakte lila Meldungen mit Cheat-Namen, Hover-Details, Klick zum Zuschauen und Spam-Drosselung.

Ehrlich gesagt: Reine Anzeige-Cheats wie ESP, Tracers, Fullbright, Xray oder Freecam senden nichts an den Server – die kann kein Anticheat sicher erkennen. Gegen Xray hilft der Anti-Xray, der Erze für Clients verschleiert.

Installation

In zwei Minuten startklar.

Jar herunterladen – auf der Release-Seite die Datei noskillanticheat-bukkit-….jar laden.

In den Plugin-Ordner legen – nach plugins/ deines Paper-, Folia-, Purpur- oder Spigot-Servers (Minecraft 26.x, Java 25).

Server starten – die Config wird erzeugt. Für den Anti-Xray den Server einmal neu starten.

Testen und messen – mit /nsac session start legit-pvp Fehlalarme messen, erst danach experimental-checks: true setzen.

Bereits vergebene grim.*-Rechte heißen hier nsac.*. ViaVersion und ViaBackwards werden unterstützt.

Die KI selbst trainieren

Kein Abo, keine Cloud: Die Daten bleiben auf deinem Server, trainiert wird mit reinem Python.

Aufnehmen – /nsac record start <spieler> legit-pvp für ehrliches Spiel, cheat-killaura mit Cheat-Client auf einem Testserver.

Trainieren – python3 tools/ai/train.py recordings/ --out model.json. Der Bericht zeigt Erkennungsrate und Fehlalarme pro Stunde an Spielern, die das Modell nie gesehen hat.

Einsetzen – model.json nach plugins/NoSkillAntiCheat/ai/ legen und /nsac reload.

FAQ

Ist es wirklich kostenlos?

Ja. NoSkillAntiCheat ist Open Source unter der GPL-3.0. Keine bezahlten Funktionen, keine Telemetrie – es werden keine Daten an fremde Server geschickt.

Werden ehrliche Spieler mit hohem Ping geflaggt?

Die Bewegungs-Simulation gleicht den Ping über Transaktionen aus. Neue Checks laufen zuerst experimentell: Sie melden nur, bis du mit /nsac session gemessen hast, dass sie keine Fehlalarme erzeugen.

Erkennt es jeden Cheat-Client?

Nein, das kann kein Anticheat. Meteor wird beim Beitritt erkannt, solange es die Schild-Probe nicht blockiert. Alles andere fällt über sein Verhalten auf – Flight, Speed, KillAura und Co.

Werden Mods wie Sodium oder Mouse Tweaks gebannt?

Sodium, Iris, Lunar, Voice Chat usw. nicht. Mouse Tweaks hat keine erkennbare Signatur; schnelles Item-Verschieben meldet höchstens der Inventar-Check.
