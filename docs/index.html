Das Anticheat, das Cheater beim Namen nennt.

NoSkillAntiCheat rechnet jede Bewegung nach, prüft Kampfverhalten und erkennt Cheat-Clients wie Meteor schon beim Beitritt. Kostenlos, ohne Cloud und so leicht, dass dein Server nichts davon merkt.

    Was kein Anticheat sieht: ESP, Tracers, Fullbright, Freecam und andere reine Anzeige-Cheats senden nichts an den Server. Gegen Xray hilft der eingebaute Anti-Xray, der Erze verschleiert.

    Wie die Erkennung funktioniert

    Simulation

    Jede Bewegung wird mit der echten Minecraft-Physik nachgerechnet, inklusive Ping-Ausgleich. Wer fliegt oder zu schnell läuft, wird zurückgesetzt.

    Heuristiken

    Kampf, Klicks, Inventar und Abbauen werden statistisch geprüft: zu gleichmäßig, zu schnell oder unmöglich präzise fällt auf.

    Lokale KI

    Aus aufgenommenen Sitzungen trainierst du ein eigenes Modell. Es bewertet Kampfverhalten direkt im Plugin, ohne Daten zu verschicken.

    In vier Schritten startklar

    1. Herunterladen

      NoSkillAntiCheat.jar lädt immer die neueste Version.

    2. In den Plugin-Ordner legen

      Funktioniert auf Paper, Folia, Purpur und Spigot mit Minecraft 26.x und Java 25.

    3. Server starten

      Die Config wird erzeugt und der Anti-Xray eingeschaltet. Einmal neu starten, dann ist er aktiv.

    4. Mit Velocity?

      NoSkillAntiCheat-Velocity.jar nur auf den Proxy legen. Er versteckt dort den Server-Typ.

    Häufige Fragen

    Ist es wirklich kostenlos?

    Ja. NoSkillAntiCheat steht unter der GPL-3.0, ohne bezahlte Funktionen und ohne Telemetrie.

    Werden Spieler mit hohem Ping geflaggt?

    Die Simulation gleicht den Ping aus. Neue Checks melden zuerst nur und bestrafen erst, wenn du sie freigibst.

    Erkennt es Meteor?

    Ja, beim Beitritt über die Schild-Probe, solange Meteor sie nicht blockiert. Alles Weitere fällt über das Verhalten auf.

    Funktioniert es mit TotemGuard?

    Ja. AutoTotem übernimmt das optionale Plugin TotemGuard. NoSkillAntiCheat bringt PacketEvents umbenannt mit, es gibt keine Konflikte.
