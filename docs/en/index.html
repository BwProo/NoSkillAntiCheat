NoSkillAntiCheat is a free, lightweight anticheat for Minecraft servers. It simulates every movement, checks combat behaviour, detects hacked clients such as Meteor and learns with a local AI – no cloud, no subscription.

What is inside

Built on GrimAC's proven movement simulation, extended with combat heuristics, client detection, plugin hiding and an AI pipeline.

🧭

Movement simulation

Every movement is recalculated 1:1. Flight, Speed, NoFall, Phase, Step and Timer stand out – with latency compensation and setbacks.

⚔️

Combat checks

KillAura, AimAssist, TriggerBot, AutoClicker, Reach, Hitboxes, CrystalAura and AnchorAura.

🛰️

Meteor detection

Detects Meteor on join with the sign translation probe, even when the client hides its name.

🧠

Local AI

Record sessions, train a model on your own PC, score players in the plugin. Free and without a cloud.

🙈

Plugin hiding

Blocks /pl, /plugins, /version, /help and hides plugins from tab completion. The server type shows as "vanilla".

⛏️

Anti-xray

Optionally turns on the built-in anti-xray of Paper, Purpur and Folia automatically.

🪶

Lightweight

Checks run on the netty thread, nothing blocks the main or region threads. Folia is fully supported.

💬

Clear alerts

Compact purple alerts with cheat names, hover details, click to spectate and spam throttling.

Installation

Ready in two minutes.

Download the jar – get noskillanticheat-bukkit-….jar from the release page.

Put it into the plugins folder – plugins/ of your Paper, Folia, Purpur or Spigot server (Minecraft 26.x, Java 25).

Start the server – the config is created. Restart once to activate the anti-xray.

Test and measure – measure false positives with /nsac session start legit-pvp, then set experimental-checks: true.

Existing grim.* permissions are called nsac.* here. ViaVersion and ViaBackwards are supported.

Train the AI yourself

No subscription, no cloud: the data stays on your server, training uses plain Python.

Record – /nsac record start <player> legit-pvp for honest play, cheat-killaura with a hacked client on a test server.

Train – python3 tools/ai/train.py recordings/ --out model.json. The report shows detection rate and false alarms per hour on players the model has never seen.

Use it – put model.json into plugins/NoSkillAntiCheat/ai/ and run /nsac reload.

FAQ

Is it really free?

Yes. NoSkillAntiCheat is open source under the GPL-3.0. No paid features, no telemetry – no data is sent to third-party servers.

Are honest players with high ping flagged?

The movement simulation compensates for ping using transactions. New checks start as experimental: they only alert until you have measured with /nsac session that they cause no false positives.

Does it detect every hacked client?

No anticheat can. Meteor is detected on join as long as it does not block the sign probe. Everything else is caught by its behaviour – Flight, Speed, KillAura and so on.

Are mods like Sodium or Mouse Tweaks banned?

Sodium, Iris, Lunar, Voice Chat etc. are not. Mouse Tweaks has no detectable signature; at most the inventory check reports very fast item moving.

Where does the code come from?

NoSkillAntiCheat is a fork of GrimAC (GPL-3.0). Origin and all changes are listed in NOTICE.md.
