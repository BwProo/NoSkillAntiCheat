    What no anticheat can see: ESP, Tracers, Fullbright, Freecam and other visual-only cheats send nothing to the server. Against Xray, the built-in anti-xray hides ores from clients.

    What a ban looks like

    When NSAC bans, it plays a three-second animation around the cheater: helix, lightning, title. Everyone nearby sees it; nothing in the world changes. Preview it in game:

    /nsac animation <player>

    How detection works

    Simulation

    Every movement is recalculated with real Minecraft physics, including latency compensation. Flying or running too fast gets you set back.

    Heuristics

    Combat, clicks, inventory and mining are checked statistically: too regular, too fast or impossibly precise stands out.

    Local AI

    Train your own model from recorded sessions. It scores combat behaviour inside the plugin and never sends data anywhere.

    Ready in four steps

    2. Put it into plugins/

    Questions

    Is it really free?

    Yes. NoSkillAntiCheat is GPL-3.0, with no paid features and no telemetry.

    Are high-ping players flagged?

    The simulation compensates for ping. New checks only alert at first and punish once you enable them.

    Does it detect Meteor?

    Yes, on join with the sign probe, as long as Meteor does not block it. Everything else is caught by behaviour.

    Does it work with TotemGuard?

    Yes. AutoTotem is left to the optional TotemGuard plugin. NoSkillAntiCheat ships a relocated PacketEvents, so there are no conflicts.

    Where does the code come from?

    It is a fork of GrimAC (GPL-3.0). All changes are listed in NOTICE.md.
